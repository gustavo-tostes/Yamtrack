    • Clique em “Add Generic Destination” para criar um novo webhook.

Plugin não oficial de webhooks

  1. Você precisa ter TMDB e TVDB como provedores de metadados no Jellyfin.
  2. Adicione este link de repositório ao catálogo de plugins do Jellyfin.
  3. No catálogo de plugins, instale o plugin não oficial de Webhooks.
  4. Reinicie o servidor e configure o plugin:
    • URL: {% include "app/icons/copy.svg" with classes="w-5 h-5" %}
    • Formato do payload: Default
    • Ouvir eventos apenas de: seu usuário do Jellyfin
    • Eventos: Play, Stop, MarkPlayed e MarkUnplayed

    • URL: {% include "app/icons/copy.svg" with classes="w-5 h-5" %}
